Manual Oficial de Configuração de Ambiente para Desenvolvedor Parceiro

Guia de Onboarding
Passo 1: Liberar Acesso no Repositório (Dono do Projeto)
1

Adicionar o Desenvolvedor como Colaborador

Como o repositório é privado, o parceiro só consegue baixar após ser adicionado pelo dono (italoTT1995):

1. Acesse: https://github.com/italoTT1995/EloServe/settings/access
2. Clique em "Add people" e insira o usuário do GitHub ou e-mail do parceiro.
3. O parceiro receberá um e-mail de convite com o link para aceitar (Accept invitation).

Atenção: O parceiro precisa aceitar o convite antes de tentar rodar o git clone, caso contrário receberá erro de repositório inexistente ou permissão negada.
Passo 2: Configuração no Computador do Parceiro
2

Pré-requisitos Obrigatórios na Máquina do Parceiro

O parceiro precisa ter instalado no computador:

  • Git instalado (git-scm.com)
  • Node.js versão 18 ou superior (nodejs.org)
3

Clonar o Repositório do EloServe

No terminal (PowerShell, CMD ou Git Bash), navegue até a pasta de projetos e execute:

# Clonar o repositório via HTTPS
git clone https://github.com/italoTT1995/EloServe.git

# Entrar na pasta do projeto
cd EloServe
Nota de Autenticação: Se for a primeira vez clonando um repositório privado no Git, abrirá uma janela no navegador para ele fazer login na conta do GitHub dele.
4

Instalar Dependências e Iniciar o Sistema

Dentro da pasta EloServe, rode os seguintes comandos no terminal:

# 1. Instalar todos os pacotes (React 19, TypeScript, Tailwind, Zustand)
npm install

# 2. Iniciar o servidor local de desenvolvimento
npm run dev

O terminal exibirá a URL local. Basta abrir no navegador:

➜ Local: http://localhost:5174/
Passo 3: Rotina de Trabalho e Sincronização Diária

Como ele envia alterações (Push):

Ao terminar de codar uma nova funcionalidade:

git add .
git commit -m "feat: minha alteracao"
git push origin main

Como você puxa o código dele (Pull):

Antes de começar a programar no seu dia:

git pull origin main
